## Example:
```python
def sum_digits(n):
    if n <10:
        return 10
    else:
        all_but_last,last=n//10,n%10
    return sum_digits(all_but_last)+last
```

## Take-away
1. All frames parents are global
2. Expressions are excuted top-down, but evaluated bottom-up.
