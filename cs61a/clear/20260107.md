# Cursion - cascade

### Question: in the cascade recursive function, why does the output show some numbers twice, forming a symmetric pattern around the middle
```python 
def cascade(n):
    if n<=10:
        print n
    if n>10:
        print n
        cascade(n//10)
        print n

cascade(456)
### Output 
456
45
4
45
456
```
#### Bottlenecks on the Exmple 
1. why print n after cascade(n//10)is the 456 instead of 45 since it is doing floor division inside cascade.
- because n//10 is calling the recursive funciton cascade and forming another frame, and print n following it is still in the origianl frame,so n is still 456
2. why it will created duplicated and symmetric numbers around the middle.
- because print n before and after cascade(n//10) happen twice. And due to the recursive trait, after first print n, it will go to the called recursive function casacade(n//10) and finish the whole excution inside the new frame and contniue back to execute the following print (n). So the middle one of the output only gets printed once because n<10, the other n>10 are printed twice.
