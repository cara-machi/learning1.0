
# Tricky Example with Clear understanding 
```python
def delay(arg):
    print("delay called")
    def g():
        return arg
    return g

delay(delay)()(6)()
```
## 1. why calling g does not return the print "delay called"
- 
**The frame belongs to the function being called — not to where it was defined.**
- So:
- Call delay(5) → create a delay frame.
- Call g() → create a g frame.
**Calling g() does not create another delay frame, because delay is not being called.**
### What i am expecting (but does not happen)
*“Since g was defined inside delay, calling g() should somehow re-enter delay.”*
**But definition location ≠ execution.**
*Where a function is defined only determines:*
- its parent environment (what variables it can see).
**It does not mean:**
**calling it will re-run the outer function.**
- So:
- Inner does not mean nested execution. It only means nested scope.
